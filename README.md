# Task 2 - Data Visualization and Storytelling

## Objective

Create visualizations that convey meaningful business insights using Power BI.

## Dataset

Sample Superstore Dataset

## Tool Used

Power BI Desktop

## Dashboard Components

### KPI Cards

* Total Sales: 2.30M
* Total Quantity: 38K
* Total Profit: 286K
* Total Discount: 1.56K

### Visualizations

1. Monthly Sales Trend
2. Sales by Category
3. Profit by Region
4. Sales by Segment
5. Sales vs Profit Scatter Plot
6. Top 10 Products/Cities Analysis

## Key Insights

* Technology is the highest-selling category.
* West region generates the highest profit.
* Consumer segment contributes the largest share of sales.
* Sales peak during November and December.
* Some products generate high sales but lower profitability.

## Outcome

Created an interactive dashboard that transforms raw sales data into actionable business insights through effective visual storytelling.
